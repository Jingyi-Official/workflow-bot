DAILY WORKFLOW BOT

论文与行程，一封邮件掌握。

将 arXiv 论文摘要与今日行程汇成日报，发送到你指定的邮箱。

查看源码与配置了解数据使用

01主要功能

论文摘要

按关键词检索 arXiv 论文，利用 AI 生成结构化摘要。

今日行程

只读获取 Google Calendar 当天日程，整理时间、地点和会议链接。

邮件汇总

通过 Gmail 发送 HTML 日报，并将论文摘要保存为 Markdown。

02开始使用

  1. 安装 Python 3.12，并在项目目录安装依赖。
  2. 启用 Google Calendar 与 Gmail API，准备 OAuth 凭据；首次运行完成账号授权。
  3. 设置 OPENAI_API_KEY、EMAIL_FROM 和 EMAIL_TO；在 main.py 中配置关键词和论文数量。
  4. 运行程序，或配置 GitHub Actions 定时生成日报。
pip install -r requirements.txt
python main.py

03使用前须知

这是需自行配置和运行的开源工具。网页不提供登录、账号授权或日报发送功能。

AI 摘要可能遗漏或误解信息，请以原论文为准。请仅向可信收件人发送包含日程的日报。
