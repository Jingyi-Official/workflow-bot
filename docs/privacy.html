DAILY WORKFLOW BOT

隐私与数据使用

了解页面保存什么，以及运行 Workflow Bot 时数据如何流转。

01访问本页面

这两个静态页面不调用 Google 或 OpenAI API，也不含分析或广告脚本。浏览器本地仅保存你的语言选择；托管服务可能记录访问日志。

02运行工具时使用的数据

日历：通过只读权限获取当天事件，用于生成包含时间、标题、地点及会议链接的日报。

Gmail：使用发送权限，将日报发送到你配置的收件地址；代码不读取收件箱。

论文与 AI：将完整论文 PDF 发送给 OpenAI，读取文字与页面图像后生成摘要。当前流程不将日历事件发送给 OpenAI。

03存储与第三方服务

OAuth 凭据与令牌保存在运行环境的文件中；API 密钥从环境变量读取。论文摘要保存到仓库目录；当前流程在内存中读取 PDF，不创建临时 PDF 文件。

邮件通过 Google 处理，论文 PDF 通过 OpenAI 处理；具体保留规则取决于相应服务及你的配置。收件人可以保存或转发日报。

使用 GitHub Actions 时，凭据由你配置为仓库 Secrets。现有工作流会提交工作目录中的变更，请检查提交内容，避免发布令牌或私人数据。

04停止使用与删除

停止本地任务或禁用 GitHub Actions 定时任务，并在 Google 账号中撤销该应用的授权。删除运行环境中的令牌、凭据、临时 PDF 和不再需要的摘要。

已发送的邮件和已提交的仓库历史需要分别处理。清除浏览器的站点存储可移除语言偏好。

05联系与更新

如有问题，请通过项目 Issues 联系维护者，勿提交密钥、令牌或私人日程。
